# Nightly tasks

An agent works through this list every night at **01:00 Reykjavík time**. It does
each task on its own branch and opens a pull request. Nothing goes live until you
merge it.

**To add a task**, add a line under "To do" with the next unused number:

    - [ ] 4. Make the contact form send to mirza@mirzahasecic.com

Be specific: what to change, where, and what "done" looks like. Tasks are taken
top to bottom, up to three a night. A task the agent has already done (it has a
`nightly/task-N` branch) is skipped, so never reuse a number.

Merging a task's pull request moves it to "In review" here, ticked. Delete those
lines whenever you like.
