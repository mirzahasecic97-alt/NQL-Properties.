# Fonts

Headlines use **The Seasons**, a licensed typeface. Put the files here with these exact names:

- TheSeasons-Regular.woff2 (or .otf)
- TheSeasons-Italic.woff2 (or .otf)
- TheSeasons-Bold.woff2 (or .otf)

Every page already declares them. Until the files are here, headlines fall back to Playfair Display.
